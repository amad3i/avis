# White-label платформа для стоматологических клиник

Готовый к продаже сайт стоматологии: витрина с услугами и ценами, запись на
приём онлайн, админ-панель с аналитикой, живая панель регистратуры, PWA
(«установить приложение»).

Перелицовывается под новую клинику за ~30 минут без изменения кода: единственный
конфиг бренда — `lib/site.config.js`.

## Стек

- **Next.js 15** (App Router, SSR) + React 19
- **Tailwind CSS** — цвета через CSS-переменные из БД, неоморфизм
- **Prisma 6 + SQLite** — база одним файлом, ноль внешних сервисов
- **JWT-сессии** (jose, httpOnly cookie) для админки и регистратуры
- **Vitest** — тесты критической логики

## Быстрый старт

```bash
npm install
npm run setup     # база + демо-данные (услуги, слайды, опции)
npm run dev       # http://localhost:3000
npm test          # тесты критической логики
```

| Раздел | Адрес | Пароль |
|---|---|---|
| Сайт | `/` | - |
| Админка | `/${ADMIN_PATH}` (по умолч. `/panel`) | `ADMIN_PASSWORD` из `.env` |
| Регистратура | `/${KITCHEN_PATH}` (по умолч. `/kitchen`) | `KITCHEN_PASSWORD` из `.env` |
| Health-check | `/api/health` | - |

Пути панелей настраиваются в `.env` (`ADMIN_PATH`, `KITCHEN_PATH`) — прямые
`/admin` и `/kitchen` закрыты, панели скрыты от поисковиков (noindex + robots.txt).

## Возможности

### Клиент
- Полноэкранное слайд-шоу с акциями, услуги по категориям с тарифами
- **Доп. услуги к приёму** (анестезия, седация, микроскоп…) с пересчётом цены на сервере
- Шторка записи: имя, телефон, **время приёма**, жалобы и пожелания
- Экран успеха с номером заявки, трекинг статуса, повторная запись
- PWA: установка на телефон, офлайн-страница, кэш статики

### Админка `/admin`
- Дашборд: выручка за 7 дней (график), топ услуг, средний чек, статусы
- Заявки: статусы (новая → подтверждена → пациент пришёл → приём завершён / отмена), авто-обновление
- Услуги: CRUD, тарифы/цены, фото, иконки, флаги «хит»/«показывать»
- Категории и **доп. услуги**: CRUD
- Слайды: полный редактор главной (тексты, кнопки, фото, порядок)
- Настройки: бренд, контакты, часы, соцсети, **цвета сайта**, время до подтверждения записи

### Регистратура `/kitchen`
- Живая доска заявок, звук новой заявки, подсветка просроченных
- Мини-аналитика смены: заявки, выручка, средний чек, в работе

## White-label под нового клиента (~30 минут)

1. `lib/site.config.js` — бренд, тексты, услуги, цвета (всё перекрашивается: кнопки, лого-акценты, карта, футер)
2. `/admin/slides`, `/admin/products`, `/admin/categories`, `/admin/options`: контент
3. Логотип: `lib/logo-paths.js` (зуб, инлайновый SVG) + `public/logo.svg`
4. `.env`: пароли, `AUTH_SECRET`
5. `npm run build` — перегенерирует иконки, манифест, service worker

## Деплой

- **Vercel (без БД)**: `DATA_MODE=mock` — всё работает из конфига бренда
- **VPS**: `npm ci && npx prisma db push && npm run build && npm run start`
- **Бэкап**: `scripts/backup.sh` в cron (`0 3 * * *`), хранит 30 дней
- Мониторинг: `GET /api/health` → 200/503 + статус БД

## Безопасность

- Цены и состав заявки **всегда пересчитываются на сервере** (sizeId/optionId из БД,
  проверка принадлежности позиции услуге и её активности)
- Валидация всех входных данных (типы, длины, диапазоны)
- Rate limit: не больше 10 заявок в минуту с одного IP + honeypot против ботов
- httpOnly + sameSite=lax куки, роли admin/kitchen в JWT, проверка в middleware и API
- Загрузка фото: только изображения, до 4 МБ, случайные имена файлов

## Тесты

```bash
npm test
```

Покрывают: валидацию заявки, серверный пересчёт цен, снапшот опций,
отклонение подменённых/неактивных позиций, смену статусов, rate limiter.

## Структура

```
app/            сайт, /admin, /kitchen, /order, API-роуты
components/     UI сайта + admin/ (таблицы, формы, иконки)
context/        запись на приём (клиент, бывшая корзина)
lib/            prisma, сессии, заявки, rate-limit, логи
prisma/         схема + сид; scripts/ - миграции и утилиты
public/         зубы-иконки, hero-SVG, манифест, service worker, offline
tests/          vitest
```
